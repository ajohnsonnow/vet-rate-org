## 🎥 Technical Notes for Recording

### Screen Recording Settings
- **Resolution:** 1920x1080
- **Frame Rate:** 30fps
- **Browser:** Chrome or Firefox (latest version)
- **Browser Zoom:** 100% (no scaling)
- **Extensions:** Hide/disable browser extensions for clean UI

### Data to Use (Fake but Realistic)
```
Name: John M. Veteran
SSN: 123-45-6789
DOB: 05/15/1985
Address: 123 Main Street, Apt 4B, Springfield, VA 22150
Phone: (555) 123-4567
Email: john.veteran@example.com

Condition: Chronic Knee Pain (Service-Connected)
Service Connection: "Injured during airborne training at Fort Bragg, NC in March 2015..."
Current Symptoms: "Daily pain rated 7/10, limited mobility, requires knee brace..."
Daily Impact: "Cannot run, difficulty climbing stairs, must avoid prolonged standing..."
```

### Visual Enhancements
1. **Cursor highlighting:** Use a cursor highlight tool to make clicks visible
2. **Zoom effects:** Zoom in when showing filled fields
3. **Screen annotations:** Use arrows/circles to point out key features
4. **Smooth scrolling:** Use browser smooth scroll extensions

### Audio Quality
- **Microphone:** Use a decent USB microphone (Blue Yeti, Audio-Technica AT2020, etc.)
- **Environment:** Quiet room with minimal echo
- **Background music:** Soft, inspirational music at 20% volume (royalty-free)
- **Voiceover tone:** Confident, empathetic, clear enunciation
