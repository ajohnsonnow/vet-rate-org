# 🎯 Auto-Scribe Quick Reference Card for VSOs

**Print this page and keep it at your desk for quick veteran assistance**

---

## 📋 What is Auto-Scribe?

One-click tool that **automatically fills official VA forms** (21-4138, 21-10210, etc.) with veteran's information. No typing into PDF fields. No hand-writing. Professional results in 5 minutes.

---

## 🚀 Quick Start (Show Veterans This)

### Step 1: Go to VetRate.org
```
https://vetrate.org
```

### Step 2: Click "Forms Helper"
Located in the main navigation menu

### Step 3: Select Form Type
- **Personal Statement** → VA Form 21-4138
- **Buddy Letter** → VA Form 21-10210
- **PTSD Stressor** → VA Form 21-0781
- **Intent to File** → VA Form 21-0966

### Step 4: Fill Guided Wizard
Answer simple questions in plain English (not "VA language")

### Step 5: Preview & Download
- **Green button** = Preview first (recommended)
- **Blue button** = Direct download

---

## ⚠️ Warning Messages (What They Mean)

### "Detailed Statement Detected (2100 characters)"
- **What it means:** Statement is long (good thing!)
- **What to do:** Nothing - app auto-splits across pages
- **Tell veteran:** "You're being thorough. Perfect."

### "Preview button says 'Generating...'"
- **What it means:** Creating PDF (takes 3-10 seconds)
- **What to do:** Wait patiently
- **If stuck >30 sec:** Refresh and try direct download

## 📊 Character Limits (When to Worry)

| Form | Safe Limit | Warning Threshold |
|------|-----------|------------------|
| 21-4138 | Under 3600 chars | Shows warning at 1800+ |
| 21-10210 | Under 2000 chars | Shows warning at 1500+ |

**Rule of Thumb:** If you can read the full statement aloud in under 5 minutes, it will fit.

## 🔧 Troubleshooting Decision Tree

### Problem: Downloaded PDF is blank
1. Try different browser (Chrome/Firefox recommended)
2. Disable browser extensions
3. Use "Download" option instead of "Preview"

### Problem: Text is cut off
1. Was there an overflow warning? (Orange banner)
2. If YES: Text should be on Page 2
3. If NO: Report as bug (rare)

### Problem: Can't open PDF
1. Install Adobe Reader (free)
2. Try opening in different PDF viewer
3. Re-download the file

### Problem: Veteran doesn't have their info
1. Use "Set Up Profile" feature (one-time entry)
2. All future forms auto-fill
3. Can backup profile to file

## �-️ Pro Tips for VSOs

### Tip 1: Set Up Profile First
Have veteran click "Set Up Profile" and enter:
- Name, SSN, DOB, Address, Phone, Email
- Service info (branch, dates, service number)
This auto-fills ALL future forms

### Tip 2: Use Preview for First-Timers
Veterans need to SEE it work to trust it
- Always use preview on first form
- Show them the filled fields
- Builds confidence for future self-service

### Tip 3: Print from Preview
No need to download → open → print
- Preview modal has browser print option
- Faster for in-office assistance

### Tip 4: Backup Before Leaving
Tell veteran: "Click Backup All Data"
- Saves everything to file on their computer
- Can restore on different device
- Good insurance policy

### Tip 5: Use the Buddy Letter Feature
Most veterans forget to get buddy letters
- Forms Helper has template for VA Form 21-10210
- Can email to buddy to fill out
- Auto-fills veteran's info
