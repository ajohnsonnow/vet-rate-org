DD214 Analyzer - PDF Drag & Drop Enhancement
===============================================

FEATURE ADDED: Full drag-and-drop PDF intake support

Previous Functionality:
- Click to browse and select PDF files 
- Multiple file upload 
- Automatic OCR for scanned PDFs 
- Text extraction from native PDFs 

NEW Functionality:
 Drag and drop PDF files directly into upload zone
 Visual feedback when dragging files over drop zone
 Drop zone highlights and scales when files hover over it
 Validates file types (only accepts PDFs)
 Shows clear error if non-PDF files are dropped

Technical Implementation:
- Added isDragging state to track drag status
- Implemented handleDragOver, handleDragLeave, handleDrop handlers
- Refactored file processing into shared processFiles() function
- Enhanced drop zone UI with conditional styling
- Improved user experience with visual cues

User Benefits:
- Faster workflow - no need to click and navigate file browser
- More intuitive - matches modern file upload patterns
- Better feedback - clear visual indication when dragging files
- Multiple files - can drag multiple PDFs at once
- OCR support - still works with scanned documents

Testing:
 No build errors
 Component compiles successfully
 No TypeScript/ESLint issues
