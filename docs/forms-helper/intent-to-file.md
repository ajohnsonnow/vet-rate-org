# Intent to File

Establish your claim date to protect your effective date using VA Form 21-0966.

---

## What is Intent to File?

**Intent to File** is a notification to the VA that you plan to file a claim for benefits. It:

- Establishes an effective date up to **1 year** before you file the actual claim
- Gives you time to gather evidence
- Costs nothing and has no downsides
- Doesn't commit you to filing

---

## Why It Matters

### Effective Date Impact

Your **effective date** determines when benefits begin. Without an Intent to File:

| Scenario | Effective Date |
|----------|----------------|
| No Intent to File | Date of actual claim submission |
| With Intent to File | Date of Intent to File submission |

### Real Dollar Impact

Example: You file an Intent to File on **January 1**, then submit your claim on **October 1**.

| With Intent to File | Without |
|---------------------|---------|
| Effective date: January 1 | Effective date: October 1 |
| 9 extra months of back pay | No back pay |
| At 30%: ~$4,000+ extra | $0 extra |

!!! tip "File Immediately"
    If you're considering a VA claim, file an Intent to File **today**. It costs nothing and protects your effective date.

## Submission Methods

After completing the form:

### Online (Fastest)

1. Log in to **VA.gov**
2. Go to claim submission
3. Select "Intent to File"
4. Submit electronically
5. Receive confirmation immediately

### By Mail

1. Download completed form
2. Sign and date
3. Mail to your VA Regional Office

### By Phone

1. Call VA at **1-800-827-1000**
2. Tell them you want to file an Intent to File
3. Provide your information
4. Get confirmation number

### Through a VSO

1. Give form to your VSO representative
2. They can submit on your behalf
3. Get confirmation

---

## What Happens After Filing

### Confirmation

You'll receive confirmation:

- **Online** - Immediate confirmation number
- **Mail** - Letter within a few weeks
- **Phone** - Confirmation number during call

### 1-Year Window

You have **1 year** to submit your complete claim:

| If You File Within 1 Year | If You Don't |
|---------------------------|--------------|
| Effective date = Intent to File date | Intent to File expires |
| Potentially more back pay | Must file new Intent to File |

### During the Window

While your Intent to File is active:

- Gather medical evidence
- Get nexus letters
- Obtain buddy statements
- Prepare your claim
- Consult with VSO

## Types of Claims Covered

### Compensation

For service-connected disabilities:

- New claims
- Increased rating claims
- Secondary condition claims

### Pension

For non-service-connected needs:

- Veterans pension
- Aid and Attendance
- Housebound benefits

### Survivors Benefits

For surviving dependents:

- Dependency and Indemnity Compensation (DIC)
- Survivors pension

---

## Important Rules

### One Intent to File Per Type

You can only have **one active** Intent to File per claim type:

- One for Compensation
- One for Pension
- One for Survivors

### Extending Intent to File

If your Intent to File is about to expire:

- You **cannot extend it**
- File your claim before it expires, OR
- Let it expire and file a new one (losing that effective date)

### Partial Claims

If you need more time for some conditions:

- File whatever is ready before the 1-year deadline
- You can add more conditions later (with new Intent to File dates for those)

## Tips for Success

!!! tip "Intent to File Best Practices"
    
    1. **File immediately** - As soon as you consider a claim
    2. **Document the date** - Save your confirmation
    3. **Set a reminder** - Calendar reminder before 1-year deadline
    4. **Track your window** - Know when it expires
    5. **File before expiration** - Even if claim isn't perfect
    6. **Keep evidence** - Save confirmation email/letter

## Common Questions

### Do I need to know my conditions?

No. Intent to File doesn't require listing specific conditions. You specify conditions when you file the actual claim.

### Can I file multiple Intents to File?

You can file a new Intent to File after your current one is used (claim filed) or expired.

### What if my claim is denied?

The Intent to File effective date still applies if your claim is later approved on appeal.

### Does Intent to File cost anything?

No. It's completely free.
