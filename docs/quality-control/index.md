# Quality Control

The **Quality Control** cluster is the set of tools you reach for _after_ a claim is drafted, not before. Once you've got conditions identified, evidence gathered, and a statement written, these nine tools help you stress-test your own work the way a VA rater, a Board of Veterans' Appeals (BVA) judge, or a claims examiner would — so you can spot and fix weak points **before** you submit, not after a denial arrives.

## Which Tool Do I Need?

| Situation                                                                            | Tool                        |
| ------------------------------------------------------------------------------------ | --------------------------- |
| I wrote a personal statement and want to know if it sounds "tough" instead of severe | **Red Team**                |
| I have a VA decision letter (any kind) and don't understand it                       | **Decision Decoder**        |
| I have a photo or scan of a **denial** letter specifically                           | **Denial Decoder**          |
| I want to check my saved claims/evidence for contradictions                          | **Consistency Engine**      |
| I filed an Intent to File and need to track the 365-day clock                        | **Time Machine**            |
| I want to know exactly what evidence I'm still missing for a rating                  | **Evidence Gap Visualizer** |
| I'm about to submit and want to avoid a BVA remand                                   | **Remand Risk Checker**     |
| I have a nexus letter and want to know if it's strong enough                         | **Nexus Quality Analyzer**  |
| I was denied and need to pick an appeal path                                         | **Appeals Lane Advisor**    |

## Important Disclaimer

!!! warning "No Guarantee of Outcome"
Every tool in this cluster is built to help you **spot potential issues before you file** — none of them guarantee any particular VA rating or claim outcome. Ratings and decisions are made solely by the VA.

    Before you rely on any of their output, have an accredited **Veterans Service Officer (VSO)** (free, no fees allowed) or a **VA-accredited attorney or claims agent** review your claim. Find one at [va.gov/ogc/apps/accreditation](https://www.va.gov/ogc/apps/accreditation/).
