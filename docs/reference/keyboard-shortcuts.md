# Keyboard Shortcuts

Navigate Vet-Rate.org efficiently using keyboard commands.

---

## Global Shortcuts

These work anywhere in the application:

| Shortcut | Action |
|----------|--------|
| **/** or **Ctrl+K** | Focus search bar |
| **Escape** | Close modal/dropdown |
| **?** | Show keyboard shortcuts help (if implemented) |

---

## Navigation

### Tab Navigation

| Shortcut | Action |
|----------|--------|
| **Tab** | Move to next interactive element |
| **Shift+Tab** | Move to previous element |
| **Enter** | Activate focused element |
| **Space** | Activate buttons, toggle checkboxes |

### Within Modals

| Shortcut | Action |
|----------|--------|
| **Escape** | Close modal |
| **Tab** | Navigate within modal |
| **Arrow Keys** | Navigate options/lists |

---

## Search

| Shortcut | Action |
|----------|--------|
| **/** | Focus search bar |
| **Enter** | Execute search / Select highlighted result |
| **↓ / ↑** | Navigate search results |
| **Escape** | Clear search / Close results |

---

## Modals & Panels

### Opening Features

| Shortcut | Action |
|----------|--------|
| **P** | Open My Packet |
| **S** | Open Secondary Scout |
| **Escape** | Close any open modal |

*Note: Letter shortcuts only work when not in an input field.*

### Within Wizards

| Shortcut | Action |
|----------|--------|
| **Enter** | Next step / Submit |
| **Escape** | Cancel / Close |
| **Tab** | Move between fields |

---

## Forms

| Shortcut | Action |
|----------|--------|
| **Tab** | Next field |
| **Shift+Tab** | Previous field |
| **Enter** | Submit form (in some contexts) |
| **Space** | Toggle checkbox |
| **Arrow Keys** | Select radio options |

## Accessibility Features

### Screen Reader Users

The application is designed for screen readers:

- Proper heading hierarchy
- ARIA labels on interactive elements
- Live regions for dynamic content
- Skip links (where implemented)

### Reduced Motion

If you've enabled reduced motion:

- Animations are disabled
- Transitions are instant
- Focus changes are immediate

## Tips for Keyboard Users

### General Navigation

1. Use **Tab** to find interactive elements
2. Watch for the **focus indicator** (outline)
3. Use **Enter** or **Space** to activate
4. Use **Escape** to close overlays

### Skip Navigation

If available, press **Tab** immediately after page load to find skip links.

### Form Completion

1. **Tab** through fields
2. Type to fill text fields
3. **Space** for checkboxes
4. **Arrow keys** for dropdowns and radio buttons
5. **Enter** to submit

---

## Customizing Shortcuts

Currently, Vet-Rate.org doesn't support custom keyboard shortcuts. Browser extensions may provide this functionality if needed.

---

## Troubleshooting

### Shortcuts Not Working?

- Make sure you're not in a text input field
- Try clicking outside any input fields first
- Check if a modal has focus
- Refresh the page

### Focus Not Visible?

- Check your browser's accessibility settings
- Try a different browser
- Report as accessibility bug
