# Search Results

After searching, results are displayed in a card-based grid layout. This guide explains how to interpret and interact with search results.

---

## Results Overview

When your search matches conditions, you'll see:

```
✅ Search Results (X found)
```

Results are displayed in a responsive grid:

- **Desktop:** 3 columns
- **Tablet:** 2 columns  
- **Mobile:** 1 column

---

## Search Result Card Anatomy

Each result card contains the following elements:

### Card Header

- **Condition Name** - The official VA condition name
- **PACT Act Badge** - (if applicable) Orange badge indicating presumptive status

### Card Body

- **Diagnostic Code** - 4-digit code in a badge
- **Body System** - Category tag (e.g., "Mental Disorders", "Musculoskeletal")
- **Rating Schedule** - CFR reference (e.g., "38 CFR § 4.130")

### Rating Badges

Available rating percentages shown as gold badges:

```
100%  70%  50%  30%  10%  0%
```

### Card Action

- **Click anywhere on the card** - Opens the disability details view

---

## Card Visual Indicators

### Selection State

When you click a card:

- **Border changes** - Highlighted border color
- **Shadow increases** - More prominent shadow
- **Details panel opens** - Expanded view appears below

### PACT Act Indicator

Conditions covered under the PACT Act show:

- **Orange "PACT Act" badge** - In the card header
- **Presumptive status** - No nexus letter typically needed

### Body System Colors

Each body system has a distinct color tag:

| Body System | Tag Color |
|-------------|-----------|
| Mental Disorders | Purple |
| Musculoskeletal | Blue |
| Neurological | Indigo |
| Respiratory | Teal |
| Cardiovascular | Red |
| Digestive | Green |
| Other Systems | Gray |

---

## Navigating Results

### With Mouse/Touch

1. **Scroll through results** - Results grid scrolls with the page
2. **Click a card** - Opens detailed view
3. **Click another card** - Switches to new selection
4. **Click close (X)** - Closes details view

### With Keyboard

1. <kbd>Tab</kbd> - Move focus between cards
2. <kbd>Enter</kbd> - Select focused card
3. <kbd>Tab</kbd> to close button - Navigate to close
4. <kbd>Enter</kbd> - Close details

### Rating Schedule Reference

The CFR reference tells you which section of the regulations applies:

| Reference | Covers |
|-----------|--------|
| 38 CFR § 4.71a | Musculoskeletal range of motion |
| 38 CFR § 4.130 | Mental disorders rating formula |
| 38 CFR § 4.97 | Respiratory conditions |
| 38 CFR § 4.104 | Cardiovascular conditions |
| 38 CFR § 4.124a | Neurological conditions |

### Available Ratings

The gold percentage badges show all possible ratings for this condition:

- **Higher percentages** = More severe symptoms
- **100%** = Maximum rating (total disability)
- **0%** = Service-connected but compensable at 0%

## Result Ordering

Results are ordered by **relevance**:

1. **Exact matches** - Conditions matching search term exactly
2. **Starting matches** - Conditions starting with search term
3. **Contains matches** - Conditions containing search term
4. **Synonym matches** - Conditions with matching synonyms

---

## Pagination

Currently, all matching results display at once. For searches with many results:

- First 3 results appear in the initial grid row
- Additional results appear in subsequent rows
- Scroll down to see all matches

---

## No Results State

When no conditions match your search:

```
No matching disabilities found.
```

**Suggested actions:**

- Check spelling
- Try broader search terms
- Search by diagnostic code
- Use different synonyms

---

## Result Actions

From any result card, you can:

| Action | How |
|--------|-----|
| View Details | Click the card |
| Save to Packet | Click "Save to Packet" in details |
| Build Statement | Click "Build Statement" in details |
| Download PDF | Click "Download PDF" in details |
| View on eCFR | Click the eCFR link in details |

---

## Tips for Better Results

!!! tip "Search Strategies"
    
    - **Search specific codes** if you already know the diagnosis
    - **Use common names** - "PTSD" works better than "Post-Traumatic Stress Disorder"
    - **Try multiple terms** - Different searches may reveal different conditions
    - **Check related conditions** - Look at secondary conditions in details
