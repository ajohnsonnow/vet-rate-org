# Accessibility Options

Configure color blind modes, font sizes, and motion settings for an accessible experience.

---

## Color Blind Modes

Vet-Rate.org supports multiple color vision deficiency modes.

### Available Modes

| Mode | Color Vision Type | Affects |
|------|-------------------|---------|
| **Normal** | Standard vision | Default colors |
| **Protanopia** | Red-blind | Adjusts red tones |
| **Deuteranopia** | Green-blind | Adjusts green tones |
| **Tritanopia** | Blue-blind | Adjusts blue tones |
| **High Contrast** | Enhanced visibility | Maximizes contrast |

### How to Enable

<div class="step-container">
<div class="step">
Click <strong>"♿ Accessibility"</strong> in the header
</div>
<div class="step">
Find <strong>"Color Vision"</strong> section
</div>
<div class="step">
Select your <strong>color mode</strong>
</div>
<div class="step">
Colors adjust <strong>immediately</strong>
</div>
</div>

### What Changes

When a color blind mode is active:

- Color palette adjusts for better distinction
- Status indicators use patterns/icons in addition to color
- Charts and graphs use accessible colors
- Warning/error colors are more distinguishable

## Font Size Settings

Adjust text size for comfortable reading.

### Available Sizes

| Size | Scale | Best For |
|------|-------|----------|
| **Small** | 85% | Dense information preference |
| **Normal** | 100% | Default reading |
| **Large** | 115% | Comfortable reading |
| **X-Large** | 130% | Reduced vision |

### How to Change

<div class="step-container">
<div class="step">
Click <strong>"♿ Accessibility"</strong> in the header
</div>
<div class="step">
Find <strong>"Font Size"</strong> section
</div>
<div class="step">
Select your preferred <strong>size</strong>
</div>
<div class="step">
Text resizes <strong>immediately</strong>
</div>
</div>

### What's Affected

- All body text
- Headings (proportionally)
- Buttons and labels
- Form fields
- Modal content

### What's Not Affected

- Browser chrome
- Exported PDFs (fixed size)
- External links

## Reduced Motion

For users sensitive to animations.

### What Reduced Motion Does

When enabled:

- ✅ Disables animations
- ✅ Removes transitions
- ✅ Static loading indicators
- ✅ Instant modal open/close

### How to Enable

<div class="step-container">
<div class="step">
Click <strong>"♿ Accessibility"</strong> in the header
</div>
<div class="step">
Find <strong>"Motion"</strong> section
</div>
<div class="step">
Toggle <strong>"Reduce Motion"</strong> on
</div>
</div>

### System Preference

Vet-Rate.org respects system-level reduced motion preferences:

- **Windows:** Settings → Accessibility → Visual Effects
- **macOS:** System Preferences → Accessibility → Display → Reduce motion
- **iOS:** Settings → Accessibility → Motion → Reduce Motion
- **Android:** Settings → Accessibility → Remove animations

## Keyboard Navigation

Vet-Rate.org is fully keyboard navigable.

### Key Commands

| Key | Action |
|-----|--------|
| **Tab** | Move to next interactive element |
| **Shift+Tab** | Move to previous element |
| **Enter** | Activate focused element |
| **Escape** | Close modals/dropdowns |
| **Arrow Keys** | Navigate within menus |
| **Space** | Toggle checkboxes, activate buttons |

### Focus Indicators

When keyboard navigating:

- Clear visual focus ring on active element
- High contrast focus states
- Visible in all display modes

## Screen Reader Support

### ARIA Labels

All interactive elements have:

- Descriptive labels
- State announcements
- Role definitions
- Live region updates

### Tested With

- NVDA (Windows)
- JAWS (Windows)
- VoiceOver (macOS/iOS)
- TalkBack (Android)

### Best Practices

For the best screen reader experience:

- Use headings to navigate
- Use landmark regions
- Listen for announcements
- Use reading mode for long content

## WCAG Compliance

Vet-Rate.org aims for WCAG 2.1 Level AA compliance:

### Level A (Minimum)

- ✅ Text alternatives for images
- ✅ Keyboard accessible
- ✅ No seizure-inducing content
- ✅ Navigable structure

### Level AA (Target)

- ✅ Color contrast 4.5:1 (normal text)
- ✅ Color contrast 3:1 (large text)
- ✅ Resizable text up to 200%
- ✅ Multiple ways to find content
- ✅ Visible focus states

## Reporting Accessibility Issues

If you encounter accessibility barriers:

1. Use the **Bug Squasher** tool
2. Describe the accessibility issue
3. Include assistive technology used
4. We'll work to fix it
