# Display Mode

Switch between light and dark themes for comfortable viewing.

---

## Light Mode vs. Dark Mode

### Light Mode (Default)

- White/light background
- Dark text
- Traditional document appearance
- Good for well-lit environments

### Dark Mode

- Dark background
- Light text
- Reduced eye strain in low light
- Saves battery on OLED screens

### Using System Preference

By default, Vet-Rate.org respects your system's preference:

- **Windows:** Settings → Personalization → Colors
- **macOS:** System Preferences → Appearance
- **iOS:** Settings → Display & Brightness
- **Android:** Settings → Display → Dark theme

---

## How It Works

### Automatic Detection

On first visit:

1. Checks your system preference
2. Applies matching mode
3. Saves preference locally

### Manual Override

When you manually select a mode:

1. Your choice is saved
2. Overrides system preference
3. Persists across sessions

### Respecting System Again

To return to system preference:

1. Open Accessibility Menu
2. Select **"System"** option (if available)
3. Or clear site data to reset

## Tips for Display Mode

!!! tip "Choosing the Right Mode"
    
    - **Bright environment:** Light mode reduces glare
    - **Dark environment:** Dark mode reduces eye strain
    - **Reading lots of text:** Light mode may be easier
    - **Nighttime use:** Dark mode is gentler
    - **Battery concerns:** Dark mode saves power (OLED)

---

## Accessibility Considerations

### Contrast Ratios

Both modes maintain WCAG 2.1 AA compliant contrast ratios:

- Minimum 4.5:1 for normal text
- Minimum 3:1 for large text
- Enhanced contrast for interactive elements

### With Color Blind Modes

Display mode works with color blind modes:

- Light + Protanopia ✅
- Dark + Protanopia ✅
- Light + High Contrast ✅
- Dark + High Contrast ✅

## Troubleshooting

### Mode Won't Change

- Refresh the page
- Check if JavaScript is enabled
- Clear cache and retry

### Mode Resets on Refresh

- Local storage may be blocked
- Check browser privacy settings
- Ensure cookies are allowed for site

### Colors Look Wrong

- Check if color blind mode is enabled
- Reset accessibility settings
- Try a different browser
