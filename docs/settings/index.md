# Settings & Preferences

Customize Vet-Rate.org to match your needs with accessibility options, display preferences, and data management settings.

---

## Accessing Settings

### Accessibility Menu

Click the **"♿ Accessibility"** button in the header to access:

- Display Mode (Light/Dark)
- Color Blind Modes
- Font Size
- Motion Settings

### In-App Settings

Various features have settings within their modals:

- My Packet settings
- Forms Helper preferences
- C&P Simulator options

## Quick Settings Reference

### Display

| Setting | Options | Default |
|---------|---------|---------|
| **Theme** | Light / Dark | System preference |
| **Font Size** | Small / Normal / Large / X-Large | Normal |
| **Reduced Motion** | On / Off | Off |

### Color Blind Modes

| Mode | Helps With |
|------|------------|
| **Protanopia** | Red-blind |
| **Deuteranopia** | Green-blind |
| **Tritanopia** | Blue-blind |
| **High Contrast** | General visibility |

### Data

| Setting | Description |
|---------|-------------|
| **Local Storage** | Your data stored in browser |
| **Backup/Restore** | Export and import your data |
| **Clear Data** | Remove all stored data |

---

## Persistence

All settings are saved locally and persist:

- ✅ Between sessions
- ✅ After browser restart
- ❌ Across different browsers
- ❌ Across different devices

---

## Resetting to Defaults

To reset all settings:

1. Open Accessibility Menu
2. Click **"Reset to Defaults"** (if available)

Or:

1. Clear site data in browser settings
2. Refresh the page

!!! warning "Clearing Data"
    Resetting settings by clearing site data will also remove your My Packet data. Backup first!
