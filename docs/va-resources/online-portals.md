# Online Portals

Essential VA websites and online portals for managing your benefits.

---

## Primary VA Portals

### VA.gov

**Main VA Website**

The central hub for all VA services:

| Feature | Description |
|---------|-------------|
| **Claims** | File and track claims |
| **Health** | Manage healthcare |
| **Education** | GI Bill information |
| **Records** | Access records |

**URL:** [va.gov](https://www.va.gov)

**Key Functions:**

- File disability claims
- Check claim status
- Apply for healthcare
- Download letters
- Manage direct deposit

---

### eBenefits

**Benefits Management Portal**

For managing specific benefits:

| Feature | Description |
|---------|-------------|
| **Rating Letters** | Download official letters |
| **Dependent Management** | Add/remove dependents |
| **Vocational Rehab** | VR&E applications |
| **Records** | Service records access |

**URL:** [ebenefits.va.gov](https://www.ebenefits.va.gov)

!!! info "Transitioning to VA.gov"
    Many eBenefits functions are moving to VA.gov. Check both portals if you can't find what you need.

---

### My HealtheVet

**Health Records Portal**

Manage your VA healthcare:

| Feature | Description |
|---------|-------------|
| **Appointments** | Schedule and manage |
| **Prescriptions** | Refill medications |
| **Messaging** | Secure messages to providers |
| **Records** | Blue Button health records |
| **Labs** | View test results |

**URL:** [myhealth.va.gov](https://www.myhealth.va.gov)

**Account Levels:**

- Basic — Limited access
- Advanced — More features
- Premium — Full access (verify identity)

---

### AccessVA

**Application Portal**

Single sign-on for VA applications:

| Feature | Description |
|---------|-------------|
| **VBMS** | Veterans Benefits Management System |
| **SEP** | Stakeholder Enterprise Portal |
| **Various Apps** | Multiple VA applications |

**URL:** [access.va.gov](https://access.va.gov)

---

## Specialized Portals

### VA Forms

Find all official VA forms:

**URL:** [va.gov/find-forms](https://www.va.gov/find-forms)

Search and download:

- Claim forms
- Healthcare forms
- Benefit applications
- Supporting statements

### VA Facility Locator

Find VA locations:

**URL:** [va.gov/find-locations](https://www.va.gov/find-locations)

Search for:

- Medical Centers
- Clinics
- Vet Centers
- Regional Offices
- Cemeteries

### GI Bill Comparison Tool

Compare schools:

**URL:** [va.gov/education/gi-bill-comparison-tool](https://www.va.gov/education/gi-bill-comparison-tool)

Features:

- Compare schools
- Estimate benefits
- Check school eligibility
- Review outcomes

---

## Official Regulations

### eCFR - Title 38

Full text of VA regulations:

**URL:** [ecfr.gov/current/title-38](https://www.ecfr.gov/current/title-38)

Key sections:

- **Part 3** — Adjudication
- **Part 4** — Schedule for Rating Disabilities

### Board of Veterans' Appeals

BVA decisions and information:

**URL:** [bva.va.gov](https://www.bva.va.gov)

Features:

- Search past decisions
- Appeal information
- Hearing schedules

### My HealtheVet Premium

To get Premium access:

1. Create account at myhealth.va.gov
2. Verify identity (online or in-person at VA)
3. Access full features

### Identity Verification

Options:

- **In-Person** — At VA facility with ID
- **Online** — Through Login.gov or ID.me
- **Video Call** — Virtual identity proofing
