General Questions

What is Vet-Rate.org?

Vet-Rate.org is a free, comprehensive VA disability claims command center built by a service-disabled veteran. It provides:

  • 748 validated VA disabilities - Official rating criteria from 38 CFR Parts 3 & 4 (eCFR validated Jan 2026)
  • 39 professional-grade tools - Everything others charge $10K+ for, completely free
  • 500+ secondary conditions - Discover medically-recognized linked conditions with probability ratings
  • 150+ VA glossary terms - Comprehensive jargon decoder for VA terminology
  • AI-powered analysis - C-File analyzer, Decision decoder, Nexus builder (optional, privacy-first)
  • C&P exam simulator - Practice with DBQ-aligned questions before your exam
  • Forms assistance - Auto-Scribe PDF filling for 16+ VA forms
  • Evidence building suite - Nexus Builder, Witness Bench, Symptom Logger, Blue Button X-Ray
  • Quality control tools - Red Team, Risk Assessment, Consistency Engine, War Game

Is Vet-Rate.org affiliated with the VA?

No. Vet-Rate.org is an independent educational resource created by a service-disabled veteran. We are not affiliated with, endorsed by, or officially connected to the Department of Veterans Affairs.

Is Vet-Rate.org free?

Yes, 100% free. No subscriptions, no premium features, no hidden costs, no "30% of your backpay" fees. What others charge $10,000+ for in services, we provide free forever. Built by a veteran for veterans.

Do I need to create an account?

No. Vet-Rate.org requires no registration or login. Your data is stored locally in your browser, and you maintain complete control.

Privacy & Security

Is my data safe?

Yes. Your data is stored only in your browser's local storage. It never leaves your device and is never transmitted to any server. We have zero ability to see or access your information.

Don't trust - verify: Open your browser's DevTools (F12) → Network tab, and watch as you use the app. You'll see zero data transmission. This is 100% client-side processing with no backend servers.

Do you collect any data?

No. We collect zero data:

  • No analytics
  • No tracking pixels
  • No cookies (except essential session storage)
  • No personal information
  • No account data

What happens if I clear my browser data?

Your Vet-Rate.org data will be deleted. Always backup your data before clearing browser storage using the export features in each tool.

Can I use this on multiple devices?

Yes, but data doesn't sync automatically. You'll need to export data from one device and import it on another using the built-in export/import features.

Is the code open source?

Yes. The code is available on GitHub for full transparency. You can audit the code yourself or use browser DevTools to verify no data is transmitted.

How accurate is the disability rating information?

All disability ratings are sourced directly from the official 38 CFR Parts 3 & 4 (Code of Federal Regulations). The database contains 748 validated conditions with official diagnostic codes and rating criteria, verified against the eCFR as of January 2026.

Can you help me file my claim?

No. Vet-Rate.org is an educational tool that helps you understand the process and prepare documentation. For direct claims assistance, contact:

  • A Veterans Service Organization (VSO)
  • An accredited claims agent
  • VA directly at 1-800-827-1000

VA API Integration (Optional)

What is the VA.gov API integration?

An optional feature that allows veterans to securely connect their VA.gov account to access personalized data like claims status and service history directly in the app.

Is the VA API integration secure?

Yes. It uses OAuth 2.0 with PKCE (Proof Key for Code Exchange), the industry standard for secure authentication. No passwords or client secrets are stored.

Is VA API integration required?

No. All core features work without VA.gov connection. The API integration is completely optional for enhanced functionality.
